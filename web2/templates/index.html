    def retry_after(header):
    if header is None:
        return None
    try:
        seconds = int(str(header).strip())
    except ValueError:
        return None
    if seconds < 0:
        return None
    return seconds

    I wrote it after a non-numeric Retry-After crashed the client.

  3. Analyzer

    retry_after takes header, reads seconds from it, and returns that int or None. It returns early when header is None, sets seconds with int() on the stripped text, and returns None on ValueError or when seconds is negative. That keeps a Retry-After value that is not a number from crashing the caller.
